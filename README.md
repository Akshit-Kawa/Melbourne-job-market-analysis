# Melbourne Data & Analytics Job Market — 2025

Exploratory analysis of Melbourne's data job market — which roles are growing, what skills employers want, and salary ranges by experience level.

## Key Findings

- AI/ML Analyst is the fastest growing role (54% YoY)
- Data Analyst has the highest volume of postings — most accessible entry point
- SQL, Power BI, and Python cover most graduate-level requirements
- Hybrid is the norm — 45% of postings offer it
- Graduate median salary: ~$76K | Senior median: ~$118K

## Files

- `melbourne_data_jobs_2025.csv` — 855-row dataset
- `analysis.py` — full Python analysis script
- `fig1_overview.png` — job postings, growth, salary, remote split
- `fig2_skills_salary.png` — skills demand and salary by experience

Python — pandas, matplotlib, numpy
